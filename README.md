# 🔗 Encurtador de URL

Projeto simples de uma API REST para encurtamento de URLs.

## 🛠️ Tecnologias

- Java 25
- Spring Boot
- Spring Data JPA
- Hibernate
- H2
- Maven

## 🚀 Funcionalidade

A aplicação recebe uma URL e gera uma versão encurtada para facilitar seu compartilhamento.
